# DFU Wound-Staging Prototype

Streamlit demo of a MobileNetV3-Large diabetic foot ulcer classifier with Grad-CAM localisation,
colour-heuristic wound-bed composition, and an IWGDF SINBAD score form.

**Research prototype only — not a medical device and not for clinical decision-making.**

Files: `streamlit_app.py` (UI), `dfu_core.py` (model + analysis), `requirements.txt`,
and `JSED_MobileNetV3_DFU.pth` (trained weights, from the Kaggle notebook's Output tab).
